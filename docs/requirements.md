## 1. 目的

リール「AIで収入を作る7つ」のコメント特典。コメントは「気になる番号（1〜7）」。どの番号でも同じ資料（7つ全部をまとめた1つ）をDMで送る（DM自動送信は別担当）。7つの仕事ごとに、何をするか・どう収入になるか・AIにどこを手伝ってもらうか・始め方・目標金額の目安を載せる。収入は約束しない。

成果指標:
- 読者が、気になる仕事を1つ選んで、最初の一歩（プロンプトのコピー）に進める
- 7つ全部をやる必要はない、と分かる
- 目標金額を「単価 × 数」で電卓で考えられる

## 2. 構成

ファーストビュー（1:1バナー）→ 冒頭CTA → わかること → STEP01 note → 02 Kindle → 03 YouTubeショート → 04 SUZURI → 05 Canvaテンプレ作り → 06 SNS運用代行 → 07 Instagramで商品を紹介して報酬をもらう → まとめ → ストーリー型のLINE誘導（標準構成）

各STEP: 何か → 必要なもの・収入のしくみ（箇条書き）→ 始め方（flow）→ AIに手伝ってもらうプロンプト → 目標の目安（仮定の例 or 公式の例）

## 3. 金額の方針（運用者の決定 2026-11-25）

- 目標金額はリールのテロップに出さず、この特典にだけ載せる
- 考え方は競合リール（@sato_ai_katsuyo）の「単価 × 数」。競合の数字・文章は転載せず、自分で調べた公式情報と、仮定の例で作る
- 公式で確認できたもの以外は「仮定の例」と明記する。おすすめ度は客観基準だけにし、感想の星は付けない

## 4. 公式確認（2026-11-26）

- note: カード決済の事務手数料5%、プラットフォーム利用料10%（事務手数料を引いた額に対して）、振込手数料270円（1回の振込につき）。公式の計算例は、1,000円の有料記事で事務手数料50円・利用料95円、振込585円（help-note.com 360011358873）
- KDP: 日本向けの70%ロイヤリティはKDP Select登録の電子書籍が対象、それ以外は35%。税込価格の条件あり（kdp.amazon.com help G200634500）
- Canva（公式ヘルプ・公式ブログ 2026-11-26確認）: クリエイタープログラムは、テンプレート・素材・専門分野の3種類。テンプレートクリエイターはポートフォリオを申請フォームから提出し、プログラムはベータ版で回答まで数か月かかることがある。報酬はテンプレートの利用回数（ダウンロード・印刷・プレゼンのたびに1回。無料版・プロとも対象）。提出物はすべて審査。公式ブログ（how-to-sell-canva-template）: 自分で売るのは、真っ白から作ったオリジナルのみ（既存テンプレの色・文字を変えただけは禁止）。売り先の例は、自分のサイト、BASE・STORES・カラーミー、minne・Creema、Etsy・Creative Market
- ステマ規制（消費者庁）: 2023年10月1日施行。アフィリエイト広告も対象で、広告であることが分かる表示が必要（検索結果での確認。ページでは公式ページへのリンクは付けていない）
- 国税庁 No.1906: 給与以外の所得が20万円超で原則確定申告（前回の特典と同じ確認）
